# Demo Data Packet — Self-serve Onboarding Launch

This folder contains the human-readable demo scenario packet for the live MVP walkthrough.

## Scenario

The self-serve onboarding launch was delayed to Q3 2026 because activation instrumentation and release controls were not ready. Later evidence showed manual onboarding demand exceeded the team's assumption. Leadership then proposed a late-Q2 2026 launch, creating an explicit Q2/Q3 roadmap conflict that the April checkpoint must resolve.
