# DEMO_SCRIPT.md
## Demo Script for Institution Memory Engine

## Goal
Show that the system is not just retrieving documents.
It reconstructs decision history and helps users decide what to do next.

## Demo flow
1. Show the problem: organizations lose the reason behind decisions.
2. Upload realistic artifacts.
3. Show extracted memory objects.
4. Show graph or timeline connections.
5. Ask a real question:
   - Why was this rejected before?
   - Does the current plan conflict with earlier decisions?
   - What assumptions are stale?
   - What should we do next?
6. Show answer with evidence, contradictions, stale assumptions, and recommendations.
7. Close with:
   “This is institutional reasoning over organizational memory, not just document search.”
