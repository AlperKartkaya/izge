# UI_UX_SPEC.md
## Interface Specification for Institution Memory Engine

## UX goals
The UI should feel:
- serious,
- calm,
- analytical,
- trustworthy,
- grounded in evidence.

## Main screens
- Workspace Dashboard
- Artifact Upload Screen
- Ingestion Status View
- Query Interface
- Result View
- Graph / Timeline View
- Admin View

## Recommended result sections
- Direct Answer
- Why This Answer
- Key Historical Evidence
- Contradictions / Tensions
- Stale Assumptions
- Recommended Next Actions
- Uncertainty / Missing Context

## Final UX rule
The UI should communicate:
“This system reasons over your organization’s memory.”
Not:
“This is just another AI chat box.”
